# 0.3.4 — 2026-08-25

## Changed

- **`@cyanheads/mcp-ts-core` ^0.11.5 → ^0.12.3**, the SDK v2 migration. A tool call carrying an undeclared argument key is now rejected by name instead of being silently stripped: the call comes back `isError` with `content[0].text` naming the key, carrying no `structuredContent` — a tool result, not a JSON-RPC `-32602`. Advertised tool schemas are JSON Schema 2020-12 (was draft-07) with `additionalProperties: false`, and the advertised `outputSchema` now declares the `error` envelope. HTTP also serves protocol revision `2026-07-28` alongside the 2025 revisions.
- **`MCP_SESSION_MODE` in `.env.example` set to `stateless`**, matching the Dockerfile. It previously shipped `auto`, which resolves to `stateful` — a source run and a container run disagreed on session mode.
- **Bun pinned to `1.4.0`** — `packageManager`, both Dockerfile stages, plus `--platform=$BUILDPLATFORM` on the build stage.
- **Skills re-synced from framework** — `add-resource`, `add-service`, `add-test`, `add-tool`, `api-config`, `api-context`, `api-linter`, `api-telemetry`, `api-testing`, `api-workers`, `code-simplifier`, `design-mcp-server`, `field-test`, `git-wrapup`, `polish-docs-meta`, `release-and-publish`, `report-issue-framework`, `report-issue-local`, `security-pass`, and `tool-defs-analysis` refreshed.
- **`CLAUDE.md`** — documents `ctx.requestInput`/`ctx.inputs` replacing `ctx.elicit`/`ctx.progress`, notes `ctx.log` is dual-sink (client-visible), and clarifies the `security:` changelog frontmatter and the `agent-notes` field.

## Fixed

- **`scripts/devcheck.ts`'s Security Audit step misread Bun 1.4's `bun audit` output.** Bun 1.4 renders vulnerability block headers as `pkg@1.2.3` (was `pkg  1.2.3`) and the dependency-path separator as ASCII `>` (was `›`); the classifier recognized neither shape and hard-failed even when every advisory was transitive. Both shapes are now accepted.
