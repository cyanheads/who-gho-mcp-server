# 0.3.3 — 2026-08-18

## Fixed

- **An unpaired UTF-16 surrogate in a caller-supplied string, echoed back unmodified, serialized as a lone `\udXXX` escape that strict JSON readers can't decode.** Fixed by repairing the echoed copy on the way out — seventeen echo sites across four tools and two resources, several on the success path (result fields, enrichment) that weren't part of the original report. The value sent upstream is never touched: it must reach the GHO API exactly as the caller sent it, while the echoed copy must be well-formed. A correctly paired astral character (e.g. emoji) round-trips byte-identical. ([#19](https://github.com/cyanheads/who-gho-mcp-server/issues/19))
