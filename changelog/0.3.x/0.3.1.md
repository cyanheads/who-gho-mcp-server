# 0.3.1 — 2026-08-18

Test infrastructure only — the published runtime artifact is unchanged, and no caller-facing behavior moved.

## Added

- **Test suite adopts the framework's four-lane `projects` layout.** `unit` carries the existing tests unchanged; `smoke` checks that every definition registers with a well-formed, JSON-Schema-serializable surface; `integration` runs `toolContractSuite` end-to-end (definition → handler → service → OData query string) against a stubbed upstream; `fuzz` runs `fuzzTool` property tests over the combinatorial filter/paging input space with pinned seeds ([#17](https://github.com/cyanheads/who-gho-mcp-server/issues/17)).
- `bun run test:coverage`; `@vitest/coverage-istanbul` and `fast-check` added as devDependencies.

The fuzz lane is currently green — its pinned seeds don't reach the defect under the shipped run budget. It surfaced [#18](https://github.com/cyanheads/who-gho-mcp-server/issues/18) (a lone surrogate in `indicator_code` or `dimension` throws `URIError` and burns the full retry budget), which is deliberately not fixed here.
