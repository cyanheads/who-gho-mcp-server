# 0.3.5 — 2026-09-20

## Changed

- **`@cyanheads/mcp-ts-core` ^0.12.3 → ^0.13.6.** Upstream 5xx classification now comes from the framework's status mapping rather than a local `codeOverride`: a `501` fails on the first attempt (the framework attaches `data.retryable: false`, since a method the upstream does not implement answers the same way every time), and a `504` reports `Timeout` (-32004) where it previously reported `ServiceUnavailable` (-32000). The rest of the 5xx range is unchanged, and a `504` is still retried.
- **Arguments that fail schema validation come back as `InvalidParams` (-32602), not `ValidationError` (-32007)**, carrying `data.reason: "invalid_arguments"` and a schema-derived `data.recovery.hint`.
- **Tool error text closes with a `Recovery:` line and a branchable parenthetical** — `(reason <reason>)`, extended with `retryable` / `not retryable` where the error settles it. The `Recovery:` line is dropped when the message already contains the hint verbatim.
- **An undeclared argument key whose case-folded form names exactly one declared key is rewritten to that key**, so a camelCase spelling of a snake_case parameter is accepted instead of rejected. It applies only when the declared key is absent from the call.
- **`sessionMode: 'stateless'` declared in `createApp()`.** A deployment that sets no `MCP_SESSION_MODE` now resolves to `stateless` instead of falling through to the `auto` schema default; a deployment that sets the variable is unaffected.
- **The framework skill tree moved from `skills/` to `framework-skills/`.** Claude Code and Codex auto-load a plugin's root `skills/`, so a server shipping `.claude-plugin/` or `.codex-plugin/` handed these development skills to every agent that installed it. `.mcpbignore`, `.github/CONTRIBUTING.md`, `docs/tree.md`, and the `scripts/` checks follow the path.
- **`scripts/` resynced with the framework template** — Bun 1.4 `bun audit` parsing, alias-aware `bun outdated` attribution, a worker typecheck step, a README version-badge check in `lint:packaging`, and `lint.truncationAllowlist` read from `devcheck.config.json`.
- **`AGENTS.md` ships as the harness-neutral copy of `CLAUDE.md`**; the npm tarball now carries both, plus `changelog/`.
- **Repo scaffold aligned with the template** — CodeQL is the one tracked workflow, the issue forms auto-assign and link a private security advisory, and the Claude plugin manifest carries `$schema`, author, and keyword metadata.

## Fixed

- **A caller that disconnects mid-request now surfaces `RequestCancelled` (-32011).** It previously threw `ServiceUnavailable`, which is in the retry helper's transient set, so the server kept retrying for a caller that was already gone.
