# 0.4.1 — 2026-11-14

## Added

- **`who_query_indicator_data` `data_source`:** select one source on indicators that publish several estimates for the same country, year, and sex. Rows carry `dataSourceDimType` and `dataSourceDim` when present, and `appliedFilters.dataSource` echoes the filter. Composes with every spatial filter. ([#39](https://github.com/cyanheads/who-gho-mcp-server/issues/39))
- **`who_query_indicator_data` `spatial_type` and `spatial_codes`:** query any geography type rows carry in `spatialDimType` (`GLOBAL`, `WORLDBANKREGION`, `GBDREGION`), optionally narrowed by `spatial_codes`. `spatial_type` is mutually exclusive with the other spatial filters; `spatial_codes` without it fails with `spatial_codes_without_type`. ([#40](https://github.com/cyanheads/who-gho-mcp-server/issues/40))
- **`who_list_indicators` paging:** return `offset`, `nextOffset` while indicators remain, and a `notice` when more remain, the limit was clamped, or the offset ran past the end. ([#42](https://github.com/cyanheads/who-gho-mcp-server/issues/42))

## Changed

- **`who_query_indicator_data` `limit`:** default 200 → 25 rows (maximum 1000). Follow `nextOffset` or pass `limit` for more. ([#43](https://github.com/cyanheads/who-gho-mcp-server/issues/43))
- **Framework:** `@cyanheads/mcp-ts-core` ^0.13.18 → ^0.13.22. A server launched on Node.js below 24 now exits at startup (Bun is unaffected), and `engines.bun` is `>=1.4.4`.
- **Dev dependencies:** `@biomejs/biome` ^2.6.3 → ^2.6.7, `@types/node` ^26.6.5 → ^26.6.6, `@vitest/coverage-istanbul` and `vitest` ^5.0.5 → ^5.1.0, `tsc-alias` ^1.9.9 → ^1.9.10.

## Fixed

- **Dimension value filters:** the `dim1_value`, `dim2_value` and `dim3_value` descriptions and the `no_data` recovery name the full prefixed codes returned in `dim1`, `dim2` and `dim3` (`AGEGROUP_YEARS05-14`), replacing the unprefixed `YEARS05-14` example. ([#41](https://github.com/cyanheads/who-gho-mcp-server/issues/41))
- **`who_get_indicator_metadata` descriptions:** no longer name `GHO_CLAMP_LIMITS` or a fixed 1,000-entry ceiling; `maxItems` carries the active ceiling. ([#41](https://github.com/cyanheads/who-gho-mcp-server/issues/41))
- **`who_query_indicator_data` description:** a `sex` filter on an indicator without a SEX dimension fails with `no_data`; the description said it returns empty rows.
- **`who_list_indicators` `pageInfo` description:** the example no longer states a live catalog count. ([#42](https://github.com/cyanheads/who-gho-mcp-server/issues/42))
