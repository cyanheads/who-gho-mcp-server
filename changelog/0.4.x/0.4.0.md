# 0.4.0 — 2026-10-26

## Added

- Add the who-gho-guide skill resource for dimension discovery and complete WHO comparisons.
- **`who_query_indicator_data`:** add optional `dim2_value` and `dim3_value` filters and preserve third-dimension type/value coordinates, including cause-of-death codes. Discover positions from observation rows before applying filters. (#25, #34)
- **Read limits:** clamp oversized positive integer limits to the existing page ceilings with a requested/applied notice, log and counter. `GHO_CLAMP_LIMITS=false` restores strict rejection and advertised maxima. (#35)
- **Metadata batches:** process ten entries and return ordered `unprocessedCodes` for subsequent calls, accepting at most 1,000 entries when clamping is enabled. Unprocessed entries are never classified as missing. (#36)

## Changed

- **`who_search_indicators`:** match every whitespace-separated word independently, in any order; fall back to an exact indicator-code lookup only when names have no matches. Whitespace-only searches fail validation. (#20, #23)
- **`appliedFilters.dim1Value`:** omit the populated field when `sex` overrides `dim1_value`, with an override notice. Calls remain accepted; standalone `dim1_value` retains its predicate and echo. Consumers reading the overridden field must use `sex` instead. (#27)
- **Packaging and tooling:** add Agent Plugins root manifests, ship the guide in npm, Docker and MCPB, refresh framework tooling, and update the catalog count to 3,102 indicators.

## Fixed

- **Query notices:** identify ignored empty filters; report unmatched spatial codes only on a complete first page. Describe WHO country codes, including historical codes. (#26)
- **Dimension values:** verify existence for parent-filtered zero-total results, so unknown dimensions fail instead of claiming that the filter matched nothing. (#28)
- **Metadata:** share case-insensitive identity resolution across tool and resource, returning canonical catalog codes and names while preserving dimension-only fallback. (#29)
- **Indicator names:** decode supported HTML character references once and search literal or ampersand-encoded name terms. (#30)
- **Upstream requests:** cover headers, body reads, retries and backoff with one service-operation deadline; preserve caller cancellation and classify transient HTTP error envelopes by status. (#31, #32)
- **Text output:** retain one-sided uncertainty bounds and sparse dimension fields independently, and escape caller/upstream text without altering structured values. (#33)
- **MCPB cleanup:** preserve nested skill protocol runtime modules while stripping package-root agent documentation; add archive retention and matcher regression coverage. (cyanheads/mcp-ts-core#794)
